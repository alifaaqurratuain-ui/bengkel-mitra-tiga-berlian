# Website Pemesanan dan Manajemen Servis Mobil - Bengkel Mitra Tiga Berlian

Project skripsi S1 Teknik Informatika Universitas Muhammadiyah Prof. DR. HAMKA (UHAMKA).

## 📌 Deskripsi
Website untuk mempermudah proses pemesanan dan manajemen servis mobil di Bengkel Mitra Tiga Berlian. Fitur meliputi pemesanan servis, manajemen data pelanggan, manajemen jadwal, dan laporan transaksi.

## 🛠️ Teknologi
- **Framework:** Laravel (PHP)
- **Database:** MySQL
- **Metode Pengembangan:** SDLC dengan pendekatan Rapid Application Development (RAD)
- **Testing:** Blackbox Testing & User Acceptance Testing (UAT)
